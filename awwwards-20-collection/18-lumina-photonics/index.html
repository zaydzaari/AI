Fabrication: three steps.

  1. STEP 1

    Pick a model and a temperament

    Choose from five families. Add a suffix when you need fewer refusals — the request stays the same.

    model: "core-128k"
  2. STEP 2

    Send your first request

    Point the SDK you already use at Aether's base URL. Streaming and tool calls work as before.

    baseURL: "https://api.aether.example/v1"
stream:  true
  3. STEP 3

    Ship with costs in view
