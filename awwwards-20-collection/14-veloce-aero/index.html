Components, and the time each one saves.

01 / Unified chat

Switch models mid-conversation without explaining yourself again.

The whole thread, files included, moves with you from Core to Unbound to Forge.

02 / Three temperaments

Get direct answers for fiction, red-teaming and research.

Add :low-refusal or :abliterated to a model name. Your deployment sets the policy.

03 / Coding agents

Hand off the bug fix and review a tested diff.

Forge reads the repository, plans the change, edits files and runs the tests.

04 / Long context

Ask one question across an entire repository or archive.

Atlas is designed for very large prompts. Spec shown is a placeholder.

05 / Prompt caching

Pay less every time a long prompt repeats.

Repeated prefixes are billed at the cached rate automatically.

06 / Side-by-side compare

Find the right model for your prompt before you commit.

Run one prompt on several models and compare answers and cost.

The fitting: three steps.

  1. 1

    Pick a model and a temperament

    Choose from five families. Add a suffix when you need fewer refusals; the request stays the same.

    model: "swift-32k"   // extraction
  2. 2

    Send your first request

    Point the SDK you already use at Aether's base URL. Streaming and tool calls work as before.

    baseURL: "https://api.aether.example/v1"
  3. 3

    Ship with costs in view

    Every response reports tokens, cached tokens and cost. Long prompts are cached automatically.

    usage.cost_usd → per request
